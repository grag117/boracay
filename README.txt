EXPLORE BORACAY: SUN, SAND & SEA — WEBSITE ZIP

PAGES
- index.html: Home page
- about.html: Brand story, mission, vision, target market and values
- experiences.html: Sample packages and estimated prices
- gallery.html: Boracay photo gallery and source credits
- booking.html: Interactive email-based booking inquiry form
- contact.html: Map, visitor information and FAQ
- style.css: Responsive design
- script.js: Navigation form behavior
- assets/logo-boracay.png: Logo

HOW TO USE
1. Extract this ZIP file.
2. Open index.html to preview in your browser. Images load from Wikimedia Commons and need internet access.
3. Before publishing, open script.js and replace your-email@example.com with the email address where you want to receive inquiries.
4. Upload all files and the assets folder to the root of your GitHub Pages repository. Keep index.html in the root.
5. Publish using GitHub Pages. Then create a QR code from the final published homepage URL.

IMPORTANT
- This is a static, front-end student project. The form opens the visitor's email app; it does not save bookings or send mail automatically.
- Package prices are estimates for demonstration only, not live quotes. Verify all prices, providers, operating details and policies before representing them as real offers.
- Real Boracay photos are loaded from Wikimedia Commons. Review source links and license/attribution details on the Gallery page.
- The logo was created for this website concept.
